# Map Reveal

A simple GTA V ScriptHookVDotNet script that automatically reveals the map when the game loads.

## Requirements

- Grand Theft Auto V
- ScriptHookV
- ScriptHookVDotNet v3

## Installation

1. Install ScriptHookV.
2. Install ScriptHookVDotNet v3.
3. Copy `MapReveal.dll` into:

```text
Grand Theft Auto V/scripts/
